Overview

Learned Fusion 360 CAM to create a CNC program, then checked the generated code for collisions before sending it to the machine. Imported the base block into the CNC mill and mounted the stock on top, then programmed the mill to rough the outer edges before a second, cleaner finishing pass. Created the inner rings, then swapped in a counterbore tool to cut the counterbored screw holes.
